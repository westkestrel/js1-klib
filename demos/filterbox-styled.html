Filter-box with styling

[Back to demo list]

This page is like the other filterbox demo, except that it uses the CSS rules to hide the checkboxes and instead dim and strike the labels when the box is unchecked. You might find this more aesthetically pleasing, but you will need to have instructive text or else the users may not realize that the labels are clickable.

The first column of controls also has the radio-checkbox-group class applied, which is a useful enhancement to these sorts of controls.

Controls

Click on the labels in the controls section to show and hide the relevant content.

Press and hold (or Command-click) on a label in the first column to select it and deselect all others.
