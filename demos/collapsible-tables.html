Collapsible demo using TABLE tags

This HTML page demonstrates how to use the collapsible.js script to expand and collapse sections of your page. The page consists of a table containing several <tbody class="collapsible-section"> tags, each of which contains a row with a <th> followed by one or more rows of <td> of content. Click the headings below to show and hide their content.

The visual styling of the headings when hovered and when collapsed comes from the collapsible.css file. If you do not like this styling you can craft your own CSS; it will not affect the show/hide behaviour.
